# Bounce Back: Fractured (Godot 4.2+)

Open `project.godot` in Godot 4.2 or newer and press F5. The first open takes a few seconds while Godot
imports the PNGs in `art/`. Sound is still generated in code (no audio files).

## Controls
| Key | Action |
|---|---|
| A / D or arrows | Move |
| Space / W / Up | Jump |
| E | Interact |
| Q | Echo (after you find it) |
| R | Recollection (after you find it) |
| Enter | Start / play again |

## Walkthrough (about 5 minutes)
1. **Ballroom**: wind the music box (E), then open the door.
2. **Gallery**: take the Echo orb. Press Q near the pit to reveal stepping stones, cross, then Q near the
   far wall to reveal the hidden door and open it.
3. **Corridor**: take the Recollection orb. Press R at the broken bridge, cross, then open the door with the red knob.
4. **Forgotten Room**: the Watcher encounter triggers as you walk in. Press Q near the three objects: dots
   show the order (1, 2, 3). Touch them in that order to recover the memory. Then press R at the broken
   stairs, Q at the top to reveal the exit door, and go through it.

Falling shows "Bounce back." and respawns you at the last checkpoint.

## Files
| File | Role |
|---|---|
| `main.gd` | Level layout, progression, puzzles, Watcher encounter, UI, audio mixing, ending |
| `player.gd` | Movement, coyote time, jump buffer, Echo and Recollection casting |
| `solid.gd` | Collision blocks: normal, HIDDEN (Echo) and BROKEN (Recollection), drawn with tiles |
| `interactable.gd` | Orbs, doors, music box, memory objects, exit |
| `watcher.gd` | The silhouette |
| `backdrop.gd` | Draws the area backgrounds plus everything that changes at runtime |
| `pulse.gd` | Ability ring and light effect |
| `sounds.gd` | Generated placeholder audio |
| `tools/make_art.py` | Generates everything in `art/` |
| `palette.gd` | All colours, in one place |

## Tuning (all constants at the top of each file)
- Ability radius and duration: `player.gd` (`ECHO_*`, `RECOLLECT_*`).
- Jump and speed: `player.gd`. Gaps are tuned to about 70px max so you can't fail by a pixel.
- Darkness per area: `AREA_MOD`, `AREA_LIGHT_*` in `main.gd`. Make the Forgotten Room brighter if it is too dark on your monitor.
- Level geometry, hints and checkpoints: `_build_level()` in `main.gd`.

## Art
All pixel art lives in `art/` and is drawn at 1x, then scaled 2x with nearest-neighbour filtering
(`PX` in `util.gd`), so one art pixel is two screen pixels. Sizes to match if you repaint anything:

| File | Size |
|---|---|
| `player.png` | strip of 20x27 frames: 0-1 idle, 2-5 walk, 6 jump, 7 fall (faces right, flipped in code) |
| `watcher.png` | 26x62 |
| `bg_0..3.png` | one per area, 700-800 x 340 (covers world y 0-680) |
| `floor_<area>_top/fill.png`, `tile_*.png` | 16x16 tiles (plank is 16x8, slab is 16x10) |
| `chair`, `clock`, `musicbox`, `table_musicbox`, `pedestal`, `orb_*`, `shard`, doors, `hang_lamp`, `paintings` | props |
| `font_s.fnt/png`, `font_l.fnt/png` | bitmap pixel font (lowercase, uppercase, digits, basic punctuation) |

The placeholder-free art is generated by `tools/make_art.py` (Pillow + numpy), so you can tweak colours
or shapes there and re-run it. Or just repaint the PNGs in Aseprite/Pixelorama and export over them with
the same names and sizes.

Things that are drawn in code on top of the art: candle flames, the paintings changing faces, chairs moving,
corridor doors vanishing, the pits, the tear between areas, dust, and all lighting.

## Dialogue
All text is in `main.gd` (search for `_show_text` and the `hints` list in `_build_level`). It's written as the
protagonist's own thoughts, lowercase to match the font. The font has a-z, A-Z, 0-9 and `. , ! ? ' " : ; - ( ) [ ] /`;
anything else (curly quotes, em dashes, accents) won't show up.

## Audio
Still procedural. To use real files, in `_build_audio()` in `main.gd` swap `Sounds.xxx()` for
`load("res://audio/xxx.ogg")`.

## Not included
The optional REBOUND ability. Easiest way to add it: a third `has_rebound` flag in `player.gd` that sets
`velocity.y = -650` once while airborne.

## Export
Project > Export > add Web or Windows. For Web, audio starts only after the first key press (Enter on the title screen), which satisfies browser autoplay rules.
